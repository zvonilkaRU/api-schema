# Bug report: oapicodegen v1.3.2 — path-only cross-file `$ref` на date-time схему резолвится в `time.Timestamp` (пустой стаб) вместо `model.UTCTime` при `USE_UTC_FOR_DATE_TIME=true`

**Репозиторий генератора:** github.com/ilovepitsa/oapicodegen
**Версия:** v1.3.2 (commit `051acac`)
**Проект-потребитель:** github.com/zvonilkaRU/api-schema
**Дата:** 2026-08-01
**Результат:** обновление v1.2.1 → v1.3.2 заблокировано, откат к v1.2.1.

## TL;DR

v1.3.2 починила defect #2 (path-only cross-file `$ref` → `any`) — #69 типизация разблокирована
(`LoginResponse.user` → `models.UserRequest`, `User.status` → `UserStatus`, конвертер
`models.UserRequestToResponse`). НО появилась регрессия: intra-service cross-subpackage ref на
Timestamp-схему (`format: date-time`) резолвится в `time.Timestamp` (пустой стаб subpackage'а)
вместо `model.UTCTime` (root) → `undefined: time.Timestamp`, `go build` падает.

## Симптом

```
generated/rooms/model/models/room.gen.go:16:17: undefined: time.Timestamp
generated/servers/model/models/channel.gen.go:18:17: undefined: time.Timestamp
generated/servers/model/models/server.gen.go:18:17: undefined: time.Timestamp
generated/servers/model/models/server_member.gen.go:16:16: undefined: time.Timestamp
... (room/channel/server/server_member + *_audit_data variants)
```

Единственный undefined-символ — `time.Timestamp`. Остальные `any`-поля (UUIDv7 cross-project и др.)
НЕ блокируют сборку (остаются `any`, `GOLANG_SCHEMA_ANY=warn`).

## Воспроизведение

zvonilka, one-schema-per-file, кастомный `name:`-формат. rooms имеет **локальный** Timestamp.

`rooms/src/openapi/openapi.yaml`:
```yaml
components:
  schemas:
    Timestamp:
      $ref: "./schemas/time/Timestamp.yaml"
```

`rooms/src/openapi/schemas/time/Timestamp.yaml`:
```yaml
name: Timestamp
type: string
format: date-time
x-validations: ["app.UTCDateTime"]
```

`rooms/src/openapi/schemas/models/Room.yaml` (cross-subpackage intra-service ref):
```yaml
properties:
  created_at:
    $ref: "../../schemas/time/Timestamp.yaml"   # schemas/models/ -> schemas/time/
```

Флаг: `USE_UTC_FOR_DATE_TIME=true`.

## Сгенерированный код (НЕ компилируется)

`generated/rooms/model/models/room.gen.go`:
```go
package model

import (
	"fmt"
	validator "github.com/ilovepitsa/oapicodegen/pkg/validator"
	time "github.com/zvonilkaRU/api-schema/generated/rooms/model/time"
)

type RoomRequest struct {
	CreatedAt time.Timestamp `json:"created_at"`   // ← undefined: time.Timestamp
}
```

`generated/rooms/model/time/timestamp.gen.go` — **пустой стаб** (5 строк):
```go
// Code generated by oapigen (dev), DO NOT EDIT.

package model

// RFC3339 timestamp в UTC. С USE_UTC_FOR_DATE_TIME флагом генерируется как model.UTCTime.
```

Настоящий тип — `generated/rooms/model/utc_time.gen.go` (root model-пакет):
```go
package model
import ("encoding/json"; "time")
type UTCTime time.Time
func (u UTCTime) MarshalJSON() ([]byte, error) { return json.Marshal(time.Time(u).UTC()) }
```

## Корневая причина

С `USE_UTC_FOR_DATE_TIME=true` Timestamp-схема рендерится как `model.UTCTime` (root); в subpackage
`model/time/` остаётся пустой стаб без типа (файл создаётся, но тип в него не пишется).

В v1.3.2 новая path-only ref-резолвция (`refToSchemaName` стрипает расширение → `walkNested` находит
схему "Timestamp" → `ExternalRef` не выставляется → `qualifyModelType`) резолвит поле в
**`time.Timestamp`** (subpackage-путь), а не применяет `qualifyUTCTime` → `model.UTCTime`.

В v1.3.0 `qualifyUTCTime` добавлен именно для subpackage-контекста. Но новый code path v1.3.2
(path-only ref → `qualifyModelType`) его, видимо, не проходит — резолвит в subpackage-тип вместо UTCTime.

До v1.3.2 этот ref был `any` (неразрешён) → пустой стаб никем не использовался → компилировалось.

## Ожидаемое поведение

При `USE_UTC_FOR_DATE_TIME=true` поле с `$ref` на Timestamp (`format: date-time`) должно рендериться:
```go
CreatedAt model.UTCTime `json:"created_at"`
```
(с импортом root model-пакета), а НЕ `time.Timestamp` на пустой стаб.

Варианты фикса:
1. В path-only ref-резолвции v1.3.2 — прогонять `qualifyUTCTime` (проверка `USE_UTC_FOR_DATE_TIME` +
   `format: date-time`) перед квалификацией поля как `<subpkg>.Timestamp`.
2. И/или не создавать пустой стаб `model/time/timestamp.gen.go` при `USE_UTC_FOR_DATE_TIME`
   (тип живёт в root как UTCTime — stub-файл не нужен, только сбивает резолвер).
